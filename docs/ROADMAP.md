# Roadmap

Glassbox follows the chapters of a classic visual introduction to neural
networks. Each chapter becomes one "island" on the learning map.

| Island | Concept | Status |
|---|---|---|
| Digit Island | What a neural network is, training, loss, learning rate | ✅ Playable |
| Downhill Valley | Gradient descent, the cost landscape | Planned |
| Blame Bridge | Backpropagation, step by step | Planned |
| Word City | Next-token prediction with a tiny transformer | Planned |
| Highlighter Tower | Attention heads, queries, keys and values | Planned |
| Memory Palace | How MLP layers store facts | Planned |
| Surprise Lake | Cross-entropy as surprise, compression | Planned |
| Noise Lake | Diffusion: from noise to a picture | Stretch |

## Principles

1. **Play first, name second.** Every concept is experienced before it is named.
2. **One screen, three depths.** Story, Tinker and Math modes show the same
   visual with increasing detail.
3. **Built from scratch.** The neural network engine is plain NumPy, so every
   number on screen can be traced back to readable code.

## Next for Digit Island

- Save a trained robot so learners can come back to it.
- A "race" mode: compare two learning rates side by side.
